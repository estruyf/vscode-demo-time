## 🚀 Highlights

- **Code blocks that tell the story**  
  ([#452](https://github.com/estruyf/vscode-demo-time/issues/452), [#422](https://github.com/estruyf/vscode-demo-time/issues/422),
  [#441](https://github.com/estruyf/vscode-demo-time/issues/441), [#439](https://github.com/estruyf/vscode-demo-time/issues/439))
  Highlight lines, step through them click by click, animate the code from one version to the next
  with `magic-move`, and show the code of a file in your workspace that stays up to date.

- **Scene checkpoints**  
  ([#460](https://github.com/estruyf/vscode-demo-time/issues/460)) Go back to a scene and its files
  are restored before it runs again. Reset the whole play to how it started, or jump to any scene
  with `Demo Time: Reset to scene...`. Your own git repository is never touched.

- **Drawing on slides**  
  ([#445](https://github.com/estruyf/vscode-demo-time/issues/445)) Press `D` and mark up the slide
  with a pen or highlighter, with a mouse, a pen or touch.

- **Include slides from other files**  
  ([#426](https://github.com/estruyf/vscode-demo-time/issues/426)) Write your "about me" or "thank
  you" slide once and include it in every talk with the `src` front matter property.

- **A slide editor in the preview**  
  Slide thumbnails you can drag to reorder, a speaker notes pane like in PowerPoint, and slide
  actions in the right-click menu.

## ✨ New & Notable Features

### Code Blocks on Slides

- **Line highlights, title, caption and line numbers**
  ([#452](https://github.com/estruyf/vscode-demo-time/issues/452)) – ` ```ts {1-3} `, `title`,
  `caption` and `showLineNumbers` now work, with styles in all themes. A code block with a title
  shows as one box. Themes can change the colors with the `--demotime-code-*` CSS variables.

- **Shiki notations** ([#452](https://github.com/estruyf/vscode-demo-time/issues/452)) – Mark lines
  in the code with `// [!code ++]`, `// [!code --]`, `// [!code focus]`, `// [!code highlight]`,
  `// [!code error]`, `// [!code warning]`, `// [!code info]` and `// [!code word:name]`.

- **Line steps** ([#422](https://github.com/estruyf/vscode-demo-time/issues/422)) –
  ` ```ts {1-2|4-6|all} ` highlights the next range on every click and dims the other lines. They
  are click steps, so they work with the arrow keys, clickers, the remote control and auto-advance.
  `clicks=2` starts them on a later click.

- **Animated code changes** ([#441](https://github.com/estruyf/vscode-demo-time/issues/441)) – Put
  a code block for every step in a ` ````md magic-move ` block. On every click, the code that stays
  moves to its new place, new code fades in and removed code fades out, in the colors of your VS
  Code theme. Supports `title`, `caption`, `showLineNumbers`, `clicks` and `duration`.

- **Code from workspace files** ([#439](https://github.com/estruyf/vscode-demo-time/issues/439)) –
  ` ```ts file="src/app.ts" ` shows the code of a file, with `#L10-24` for a line range or
  `#region=setup` for a region. The preview updates when you save the file, and a missing file,
  range or region shows an error on the slide and in the **Problems** panel.

### Scene Checkpoints

- **Restore files when you go back**
  ([#460](https://github.com/estruyf/vscode-demo-time/issues/460)) – Turn it on with the
  `demoTime.sceneCheckpoints` setting or the `sceneCheckpoints` property of an act. Demo Time
  snapshots the workspace files when a scene starts and restores them when you go back to it.

- **Reset** – `Demo Time: Reset` restores the files as they were before the first scene, and
  `Demo Time: Reset to scene...` restores and reruns a scene of your choice.

- **Separate repository** – The checkpoints live in their own git repository, so your repository
  is never changed. Going back is allowed while scene checkpoints are on, unless you set
  `demoTime.previousEnabled` yourself.

### Slides

- **Drawing on slides** ([#445](https://github.com/estruyf/vscode-demo-time/issues/445)) – Turn it
  on with the **Toggle drawing** button of the slide controls or `D`. Pick a pen or highlighter in
  six colors, the eraser or **Clear drawings**, and press `Escape` to stop. Drawings stay on their
  slide when you come back, are removed when presentation mode turns on or off, don't count as click
  steps and are not part of the PDF export.

- **`src` Front Matter Property**
  ([#426](https://github.com/estruyf/vscode-demo-time/issues/426)) – The slide is replaced by all
  slides of another markdown file. Included slides keep their own front matter, the `theme` and
  `customTheme` of the including file win, and properties next to `src`, like `hide: true`, apply
  to every included slide. Slide numbers, the navigator, the thumbnails, the next slide preview and
  the PDF export count the included slides.

### Slide Preview

- **Slide thumbnails** – Show the slides of the file in order. Click a thumbnail to open the slide,
  drag it or press `Alt+Up` / `Alt+Down` to reorder, and right-click it for the slide actions. Turn
  them on or off with the **Toggle slide thumbnails** button or the
  `demoTime.slidePreviewThumbnails` setting.

- **Speaker notes pane** – Type the notes of the current slide below the preview, saved in its
  `<!-- notes -->` block. Turn it on or off with the **Toggle speaker notes** button or the
  `demoTime.slidePreviewNotes` setting.

- **Right-click menu** – **Show slide contents**, **Change layout**, **Hide slide while presenting**,
  **Insert slide after**, **Duplicate slide**, **Delete slide**, **Move slide up** and **Move slide
  down** update the markdown file for you.

- **Arrow keys move between slides** – Outside presentation mode, the arrow keys, `PageDown` and
  `PageUp` go to the next and previous slide, like the **Next** and **Previous** buttons.

- **Opens to the side** – `Demo Time: Open slide preview` opens the preview next to the markdown
  file instead of on top of it, and the focus stays in the editor.

### Moves

- **`pollInPreview` Property** – Show the `showEngageTimePoll` poll in the Demo Time preview instead
  of the integrated browser, so the next and previous keys and clickers keep working.

## 🛠 Improvements & Fixes

- **Scene navigation** – Next, previous and running another scene are ignored while the moves of a
  scene still run, so a quick second press can't start a scene next to it.
- **File moves** – `copy`, `move` and `rename` wait for the file operation before the next move
  starts.
- **Going back across slide files** – The previous scene opens its slides on the last slide instead
  of the first one.
- **Slide numbers** – `{{crntSlideIdx}}` and the progress bar follow the order of the act files.
- **Overview** – Clicking a slide opens that slide instead of the one before it.
- **Presenter view** – The next slide preview shows the latest version of the slide.
- **Remote control** – The previous button and `/api/previous` respect `demoTime.previousEnabled`.
- **Column markers in code** – A `::right::` or `::section::` marker in a code block or inline code
  no longer splits the slide.
- **Slide controls** – The controls and cursor stay visible while the mouse is on them or a menu is
  open.
- **PDF export and screenshots** – Styles with quotes or a `>` selector, relative `url()` fonts and
  images in custom themes, `{{metadata.webViewUrl}}` images in custom layouts, and centered elements
  split over two pages are fixed.
- **Analytics** – The slide timeline no longer mixes slides of the previous scene in, the scene
  numbers are right when you go back or run a scene by id, and the **No Timer** status is readable.
- **EngageTime polls** – `startOnOpen` and `closeOnOpen` no longer pause the poll; the message shows
  in the status bar.
- **Pro Features** – **Authenticate with GitHub** no longer stays on `Authenticating...`.
- **Output channel** – Every line in the **Demo Time** output channel has a time.
- **Menus** – **Export slides to PDF** moved to the **...** menu of the Acts & Scenes view, and
  **Show demos** / **Close sidebar** are now **Show scenes** / **Hide scenes**.
