# tiny-links

A URL shortener in one file, built live on stage.

```bash
npm start      # http://localhost:8080
npm run try    # shortens a few links and follows them back
```

## Watch it as a video

The whole talk exports to a video, with captions from the speaker notes and a chapter per scene:

```bash
npm run video   # .demo/exports/demo.mp4, demo.srt and demo-chapters.txt
```

In VS Code, **Demo Time: Export play as video** does the same. The choices are saved in
`.vscode/settings.json`, so it offers **Export again**. See
[Export a play as a video](https://demotime.show/features/video-export/).
